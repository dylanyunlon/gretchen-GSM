# Gretchen — Fine-Grained Subgraph Matching on Heterogeneous GPU Systems

> *"Meine Ruh ist hin, mein Herz ist schwer, ich finde sie nimmer und nimmermehr."*
> — Gretchen, Faust I

Gretchen's tragedy lies in a fine match gone wrong —
fine-grained subgraph matching across heterogeneous GPUs demands
precise task assignment based on subgraph size and computational complexity.
